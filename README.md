## 📋 About This Project

This portfolio website showcases **Momina Sheikh's** work as a **Personal Brand Strategist and Social Media Manager**. It highlights her expertise in:

- 🎯 **Personal Brand Architecture**
- 📊 **LinkedIn Profile Optimization**
- ✍️ **Strategic Content Development**
- 📈 **Organic Growth Systems**
- 🎨 **Visual Brand Identity**
- 💡 **Brand Positioning Strategy**

The website is designed to attract founders, startups, and personal brands looking to build **authority, visibility, and trust** through strategic digital presence.

---

## ✨ Features

- ✅ **Responsive Design** — Mobile-friendly and works on all screen sizes
- ✅ **Typing Effect** — Dynamic hero section with animated text
- ✅ **Testimonial Carousel** — Auto-sliding client testimonials with client images
- ✅ **Portfolio Gallery** — Clickable image cards with lightbox popup
- ✅ **Netlify Forms** — Contact form with Netlify integration
- ✅ **Smooth Scrolling** — Seamless navigation between sections
- ✅ **Interactive UI** — Hover effects, animations, and glow effects
- ✅ **Brand Logos** — Social media icons with hover effects
- ✅ **Work Page** — Separate page with all portfolio work
